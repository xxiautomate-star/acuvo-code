## DELIBERATELY NOT DOING

**Anything that assumes paid GPU** â€” the owner ruled it out verbatim. So: no issuing Modal credentials (Tier 1 item 25 states the split honestly instead), no hosting media endpoints for strangers, no talking-head or voice work inside the CLI. The `generate_image` default endpoint is a *decision to close*, not a capability to grow.

**Building our own browser driver.** `lib/tools.mjs:166-177` already confesses that Playwright MCP and Chrome DevTools MCP are free and one install away. Curation is the edge, not access â€” ship them as a curated default (Tier 1 item 27) and keep the token-cheap verdict on top.

**PR-review automation as a differentiator.** GitHub's own agent does this inside the PR UI with zero install and home-field advantage. Build it as parity only, if item 16 lands and users ask; never lead with it.

**"Better planning" as a modelling claim.** Long-horizon decomposition is precisely where every frontier lab is spending in 2026 and a 12-month lead is not purchasable. We ship the *affordability* framing or we don't ship the claim.

**MCP resources and prompts.** Verified missing (`lib/mcp.mjs:321` is the only `tools/list` call) â€” but no payer evaluates a coding CLI on protocol surface completeness. Strategy-deck value, not purchase value.

**JVM / .NET / PHP / C++ presets ahead of demand.** Each is a grammar plus tests plus a Windows resolution trap, and `./gradlew` is agent-writable shell with a daemon that never exits. Build **one**, when a named prospect asks.

**A search index or a bundled ripgrep.** `MAX_FILES_SCANNED=4000` (`lib/search.mjs:78`) is reported honestly, so the failure is loud. The index is a small database with a cache-coherence problem (weeks); `@vscode/ripgrep` breaks the zero-dependency line, which is a real selling point. Do not start until a real repo hits the cap.

**Shell completion.** Corrected to about a day for three dialects, changes no capability, and every rival ships it â€” pure polish with nobody to notice.

**Per-seat machine ids and team attribution.** Unsellable until there are seats, and adding a machine id to a log whose stated promise is that it contains nothing identifying (`lib/audit.mjs:74-104`) is a real privacy regression bought for a benefit that does not exist. Land it *with* the gateway or not at all.

**`docs-truth` assertions over prose comments.** Proposed twice in the source lists; rejected. A regex over English in a codebase whose comments *are* the documentation is a machine for turning correct work red â€” the exact failure this repo has paid for four times. Keep every assertion against a **parsed value**: a flag row, a constant, an array length.

**A local licence `if`.** Anyone can delete it in ten seconds in an MIT public repo, and pretending otherwise costs more credibility than the gate is worth.

**Concurrent tool calls, ahead of anything.** Correct diagnosis, real fix, filler priority â€” nobody has ever chosen a coding agent because its reads were parallel.
